# TEST-001：官方测试入口（旧方案已停用）

关联：[Issue #8](https://github.com/MindScrath/Focos/issues/8) · 状态：旧方案已停用，新的运行入口规格待官方流程核实后另行审阅。

## 当前目标

为仓库提供可重复运行的比赛测试入口，沿用对应版本的测试程序、脚本、原始输出和官方判分方式。范围保持为 2025 初赛原 11 组与比赛冻结版本 LTP，覆盖 QEMU RISC-V 的 musl/glibc；区域赛目标见 [REGION-001](REGION-001.md)。

仓库负责准备运行环境、提供入口、保存完整日志以及处理启动失败、超时、中断和进程清理。测试脚本退出 0 不直接代表全部通过，参考 Linux 结果不计为 FocOS 成绩。有对应版本的官方判分工具时原样接入；没有时按官方标准核对，不自行生成通过率或“全套通过”结论。

## 本次清理

旧 A0–A3 解析路线、PROFILE/CRITERIA、自研判分、运行包重判和 campaign 契约不再作为实现要求。对应规格、审计工具、专用测试和样本已从当前文件树移除。历史内容保留在 [main 清理前的提交](https://github.com/MindScrath/Focos/tree/5a81ce1255b51bad86d1241f40dab54f7a1651ee)，不作为当前接口或验收依据。

本页仅保留目标和停用说明，不定义新的 CLI、包格式或判分协议。官方版本与运行方式核实、新 SPEC 和最小入口均留待后续工作；当前仍未提供比赛测试入口，也没有全套通过成绩。
