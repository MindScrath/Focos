# TEST-001：分开采集证据与日志判分

关联：[Issue #8](https://github.com/MindScrath/Focos/issues/8) · 状态：重设计草案，待非作者审阅

## 要做到什么

将 2025 初赛全部测试（原 11 组及比赛冻结版本 LTP）拆成固定输入、构建、采集、判分四个阶段。一次采集可以被不同版本的判据重复分析，原始证据不变；日志全部判为 PASS 也不能单独证明某个平台通过。本次只交付设计，以下命令、数据格式和测试均待实现。

## 行为约定

- **入口**：拟定 `test001 build / capture / analyze / campaign` 四个子命令（按 A–D 分期实现）。`build` 接受已审查的冻结输入，产出含内核、initramfs 和已校验基盘的独立构建包；`capture` 接受构建包与显式冻结的 `--firmware`，复制并哈希实际 OpenSBI，以该副本生成 QEMU 参数（禁止默认固件搜索），产出运行包；`analyze` 接受运行包或外部日志，产出独立报告；D 的 `test001 campaign --plan PLAN --out NEW_CAMPAIGN` 负责采集前登记、逐槽执行与完整批次汇总。首版只采集参考 Linux/QEMU；FocOS 和真板采集另行定义适配器，不接受自由平台标签或 shell 命令。
- **所有权**：每阶段只写自己独占的新目录，目标已存在即退出 2。依赖先复制到私有快照，再对实际使用的字节校验并记录哈希；不从可变原路径重新执行。完成清单最后发布，缺清单的目录是未完成产物；旧证据、输入和失败现场都不覆盖。
- **边界**：采集状态、协议状态、每组日志完整性和判分状态分字段保存，不相互改写。截断段即使已有成功输出也不计有效通过。未知名称另列、缺项为零、重复或非法判据输出失败；单位不同的分数不相加。
- **可信度**：独立日志一律为 `external_log`，subject/platform 均为 `unknown`；校验完整运行包可为 `recorded_capture`，表示本工具记录的本地运行条件，不是外部认证。无效来源、采集超时/非零退出、协议错误、脚本失败均禁止报告验收通过；逐项观察值仍保留。参考 Linux 结果始终只作校准。
- **验收范围**：运行包绑定版本化测试配置及显式调用集合，构成唯一分母（LTP 动态断言另计），分析时不能缩小；范围外项目不记缺失。单组通过只代表该范围；全套由 D 阶段批次执行器在采集前登记全部槽位，每槽最多启动一次，失败/未完成记录必须纳入；每槽须有独立的单组单 libc 运行，LTP 可按预审用例或固定分片划槽；槽位无重叠且完整覆盖冻结调用集合，运行包与报告不能重复引用；另行核对全部槽位的覆盖，以及构建、采集、分析与 campaign/汇总实现、实际固件哈希和运行条件的一致性。
- **重判**：采集 PROFILE 与分析 CRITERIA 独立版本化；analyze 显式选择已审判据，可对支持的旧运行包另存报告，保持采集身份和分母不变。批次预登记两种身份，重判报告不能替换原子报告或汇总。
- **LTP**：运行适配器随采集配置冻结，结果适配器随分析判据冻结；逐调用保存原生 TPASS/TFAIL/TBROK/TCONF/TWARN、退出码与动态计数。跳过、异常和警告不计通过；不按输出数量或 FocOS 缺失能力缩小分母。环境、设备、权限、资源及清理策略在启动前登记，失败保留证据并阻断验收。
- **退出**：2 为调用/输入错误，启动前拒绝；1 为阶段执行或发布失败。普通 `analyze` 完整生成报告即退出 0，即使报告为 BLOCKED 或包含 JUDGE_ERROR；只有加 `--require-pass` 时，验收条件不满足才使已生成报告的分析退出 1。build/capture 的成功只表示自身阶段完成，campaign 仅全套 PASS 时退出 0，详见参考页退出码表。
- **资源**：超时终止并回收整个采集进程组；串口原始字节保留，超过显式字节限额终止并记 `OUTPUT_LIMIT`。磁盘采用私有只读基盘与写时复制层；判据子进程有时间及输出限额。磁盘满、发布失败不得留下可消费的完成清单。

## 怎样验收

| 场景 | 待实现检查 | 应看到什么 |
| --- | --- | --- |
| 外部全 PASS 日志 | analyze；再加 require-pass | 普通分析退出 0；加 require-pass 退出 1，均标来源未知 |
| 超时且末段缺 END | 采集故障注入 | 同时保留采集 TIMEOUT、段 TRUNCATED 与已观察值，有效通过为零 |
| 并行构建、输入换名、输出链接 | 所有权负例 | 各阶段只消费私有快照；旧证据不变，无完成清单不消费 |
| 缺结果后重试、非法数值、未知名称 | 判分负例和固定日志回放 | 不能靠后次成功覆盖失败；未知项不改分母 |
| 判据升级 | 同一运行包按 J1/J2 分别 analyze | 不重启 QEMU；采集身份/分母不变，新判据另存报告且不能替换原批次结果 |
| 全套入口 | campaign --plan PLAN --out NEW_CAMPAIGN | 采集前按配置登记全部槽位，失败/缺结果仍保留且全套阻断；全套通过退出 0，否则 1，非法计划为 2 |
| LTP 语义与分片 | 混合 PASS/TCONF、TBROK、TWARN、无结果、重复调用、分片漏项/重叠 | 原生结果保留；验收阻断；计划错误启动前拒绝 |
| 真实环境 | QEMU 双 libc 的 Lua 与前置动作故障 | 有实际退出码、原始串口和输入身份；失败前置动作之后无测试执行 |
