# PLAT-001：隔离板型与启动资源

关联：[Issue #2](https://github.com/MindScrath/Focos/issues/2)、[#3](https://github.com/MindScrath/Focos/issues/3)、[#11](https://github.com/MindScrath/Focos/issues/11) · 状态：草案

## 要做到什么

同一 CPU 架构可选择不同机器，板级层向公共内核交付经过校验的资源并装配驱动。先接 QEMU RISC-V 与 VisionFive2，全国赛再接 LoongArch QEMU 与星云板。

## 行为约定

- **构建选择**：每次构建最终解析为一个 Rust 目标和一个板型。未显式选择时，仅允许使用已声明的默认板型，并打印选择结果；无默认且漏选、多选或架构不匹配时构建失败。构建产物和证据标明板型、固件及加载方式。具体选择命令在实现 PR 中补齐。
- **启动描述**：统一提供 RAM 区间、保留区、启动核、可用 CPU、时间源及设备资源；资源可以来自设备树、固件表或经验证的固定配置。记录来源并校验长度、溢出和地址范围，缺少必需信息时报错。RAM 描述不能重复分配；保留区可以位于 RAM 内或彼此重叠，按并集排除，不能将这种重叠误判为非法布局。
- **内存交接**：排除固件、内核、栈、元数据、启动信息和已装载镜像；MMIO 不作为 RAM 分配。描述引用必须覆盖使用期，临时固件数据须复制或保留其内存。早期用静态存储，不能依赖尚未初始化的堆。给公共分配器的区间须互不重叠；多区间支持未就绪时显式拒绝或报告限制，不能错误合并内存空洞。
- **初始化顺序**：最小架构入口/栈、必要的早期映射与早期输出 → 校验启动资源 → 公共物理内存与必要映射/DMA服务 → 控制器及设备 → 公共内核运行。早期映射使用启动保留资源，不依赖普通分配器。先用轮询建立不依赖 IRQ/调度的时间源，再初始化需要超时的设备；设置 CPU 异常入口和中断控制器后，按 DRV-001 注册处理器、清理事件并启用 IRQ；其他核保持停驻直到 SMP 专项验收。
- **设备装配**：板级层提供 MMIO 范围、IRQ 拓扑、时钟/复位/引脚、DMA 能力及所需总线资源，选择驱动，并把初始化成功的设备交公共设备注册表；注册表持有设备，板级层不另建运行时副本。固定地址只属于对应板型或控制器定义；同架构不同板不得共享未经核对的地址和频率。
- **失败**：必需资源或设备初始化失败时报告板型、阶段和原因，停止该启动路径，不输出成功标记。可选设备失败时明确降级；每个平台 SPEC 要列明必需/可选设备及早期日志途径。

## 平台运行配置

每个平台随实现提交一份版本化运行配置；可引用已有配置文件，必须能还原实际使用的值；尚未接入的设备或用户态项目明确标注“未接入”。

| 必须记录 | 用途 |
| --- | --- |
| Rust 目标/工具链、固件版本、加载方式、产物格式 | 正确构建并加载内核 |
| RAM/核数、控制台、块设备及传输方式 | 设备与板级资源对应 |
| 根设备/文件系统、测试镜像版本与哈希、初始程序及启动参数 | 启动预期负载 |
| 完整构建与运行命令；真板含固件操作步骤 | 队友独立复现 |

## 第一份实现

先按 [PLAT-002](PLAT-002.md) 和 [Issue #33](https://github.com/MindScrath/Focos/issues/33) 迁移 MM-002 已有的 QEMU 固定布局与单区间接入，保留其行为。通用启动资源校验器另拆任务，不作为 #33 的验收条件；本节顺序调整随 PLAT-002 一并审阅。

后续校验器输入是固件/固定配置转出的 RAM、保留区和来源信息；输出是页对齐、互不重叠的可分配区，或明确布局错误。校验完成前不能修改分配器；单区间分配器遇到多个结果区间时返回“不支持多区间”。重叠保留区取并集及下述 host 用例仍是该后续任务的验收要求。

host 首测：RAM `[0x1000, 0x9000)`、保留区 `[0x1000, 0x2800)` 与 `[0x2000, 0x3100)`，按当前 4 KiB 页应得到 `[0x4000, 0x9000)`；注入地址加法溢出应失败。VisionFive2 另列真实资源，不能套用此测试数据。

## 怎样验收

| 场景 | 操作或测试入口 | 应看到什么 |
| --- | --- | --- |
| 构建组合 | 合法组合、声明默认、无默认漏选、多选/错配检查（待实现） | 合法显式/默认组合成功并显示板型；其余失败，产物可区分 |
| 描述校验 | host 覆盖上述重叠保留区例子及 RAM 重复、溢出、资源冲突、缺失、多可分配区（待实现） | 合法保留区取并集；其余按约定返回错误，分配器未改变 |
| 启动与初始化失败 | 每个平台冷启动及故障场景（待实现） | 正确阶段日志；失败无成功标记、无提前开启设备 IRQ |
| 配置复现 | 另一名成员按版本化配置构建并运行（随平台接入验收） | 实际板型、设备、镜像和初始程序与配置相符；日志附配置版本与执行命令 |
| 同架构换板 | QEMU RISC-V 与 VisionFive2 各自冒烟（待实现） | 复用公共内核及 CPU 实现；各自记录实际资源和设备行为 |

沿用 [MM-002](MM-002.md) 时仍遵守其固定 QEMU 范围；替换该路径前另审迁移 SPEC。配套边界见 [ARCH-001](ARCH-001.md)、[DRV-001](DRV-001.md)；host 校验器可先于真实设备实现。初始化和内存安全需另外两名成员审阅。
