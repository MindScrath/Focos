## A0：先审计调用，再宣布冻结

每条调用包含稳定 ID、组/libc、所在脚本和位置、展开序号、实际 argv、工作目录、环境、二进制/脚本/数据身份、依赖、前置与清理、预期边界和分片。结果名到调用 ID 的映射由 CRITERIA 维护，不能从 judge 类名、最终字典或日志出现次数倒推调用集合。

审计同时交付镜像枚举工具、源码/镜像 SHA256、提取命令、逐调用表和差异表。差异表逐项解释“脚本存在但 judge 没有”“judge 存在但脚本没有”“同名计划重复”“不同 libc 不同集合”。BusyBox 尚未闭合的脚本/判据差异必须在这里解决；#46 所列 6514/24、2820/2840 仅是候选数据，不能直接复制为已冻结事实。排除项须事先审阅并列出范围影响。

父脚本调用、覆盖项、动态断言分别计数。稳定 ID 可含父调用与子项序号，但必须给出实际输入到子项的可审映射；不能把 427 个 judge 键宣称为 427 次独立程序调用。计划重复不能靠放宽重复阈值处理。若原日志不能区分两个同名调用，记录 AMBIGUOUS_INVOCATION 并阻断；新增边界标记需另发 PROFILE revision，旧日志不补造身份。

每个组进入实现前，先提交该组的语法表：固定来源位置、原始正例、必需字段/单位、上下文、允许记录次数、错误例及预期规范结果。全套 A 完成需要全部组审计闭合；可先审小组子集，不把未审计部分标成 FROZEN。

## 唯一的数据通路

```text
原始私有字节 → Record[] → 组/调用/汇总状态机 → AnalysisResult
                                                   ├─ 逐项判断
                                                   ├─ 指标与诊断
                                                   └─ 验收与 JSON/Markdown
原始私有字节 → 冻结历史 judge → reference_observation（只对照）
```

接口以数据契约定义，不强制文件名：

- `Record`：稳定 record_id、原日志字节区间、从 1 起的行号、原始字节、识别文本、角色及结构字段。原字节不覆盖；解码错误可显示转义，不能忽略坏字节再识别成功。
- `Assignment`：每记录恰有一个归属结果：组边界、调用边界、调用结果、汇总头/字段、指标、允许信息或错误。结构归属含 group/libc/invocation/attempt ID、消费规则 ID；不能仅写 consumed=true。信息归属也要有规则 ID 和所属范围。
- `InvocationResult`：稳定调用 ID、每次尝试、结束状态、原生计数、结构化 diagnostics、结果证据 ID、指标及 judgment。保留所有尝试，不用名称字典覆盖，不用集合消除重复。
- `AnalysisResult`：固定 selection、预期/观察调用序列及顺序诊断、全部记录/归属、逐调用结果、范围级错误与指标。构造结束后只读。判分、验收及渲染只消费它，不重新解析字符串、不修改它来凑通过。

证据引用是记录身份和字段值的引用，不是另一套解析器生成的 proof。某条记录可为同一调用的判断和指标同时提供证据，但只能有一个语义 owner；不能被两个调用或两次尝试借用。共享表头归属组上下文，指标引用其 ID，不能冒充额外成功事件。最终校验检查引用存在、角色匹配、归属唯一、记录无遗漏，不用第二套正则再次证明成功。

旧官方/团队 judge 原样锁定，输出只在 `reference_observation` 保存原始计数、输入哈希、实现身份及差异。不得作为最终 judgment 的输入，不能通过新 proof 修补旧 adapter 的 PASS。需要支持 basic 等组时，必须先把对应语义写进该组语法表和规范判据；未迁移的组明确拒绝为 UNSUPPORTED_GROUP（输入退出 2），不能回退调用旧 judge 判 PASS。对照工具超时、崩溃或非法输出记录独立 `reference_error`；不改变规范判断，但该轮对照验收不完成，不得声称历史校准通过。

## 字节与上下文规则

PR #56 暴露了先删 SGR 再解码会修复非法 UTF-8 的词法缺口。待审的[词法输入完整性重设计](test001-lexical-integrity.md)明确原字节、Unit、Token、合法/损坏分支的完整顺序；以下规则不允许在校验前正常化输入。

仅 LF 分记录；CRLF 的尾 CR 可用于识别时去掉，孤立 CR、VT、FF、NBSP、Unicode 行分隔不当空白或新行。结构内只允许 ASCII SP/HT；规则须锚定整条记录，不跨 LF 拼接。原始 UTF-8 必须在任何删除/正常化之前校验；控制序列不能拼接损坏字节为合法字符。ANSI 只允许经语法表枚举的完整顶层 SGR Token 在已校验识别副本中省略，并保留原位置映射；其他控制序列不用于构造成功结构。不能各组分别 strip/splitlines/去 ANSI。

先识别完整外层结构，再分类消息：`TINFO: quotes TPASS: text` 是一个信息事件，消息里的标志、组标记或 Summary 不递归解释。词法须识别合法结构和已登记保留前缀的损坏结构；非法分隔符不能把结构降成普通信息。组语法表必须定义保留前缀及合法结构所涵盖的语言，覆盖旧 adapter 曾接受的非规范变体。无法识别的普通诊断保留为 opaque 信息，不承诺识别任意伪造自然语言；缺少明确正向证据仍不能通过。

所有结构类型在全日志上识别一次，再按当前组判归属。组外、错 libc、错组和调用外的结果/汇总/指标都是带位置的错误。不能先切成功段而丢弃前后记录。匿名数字只在已登记的表格状态中解释；未知表头、非法行、中断或新上下文关闭旧状态，后续数字不得借用旧标签。

| 状态 | 合法转换 | 非法输入的确定行为 |
| --- | --- | --- |
| 组空闲/活动 | START → 当前组 → 同组 END | 重复/嵌套/错配记 ERROR；保留原活动组，错误标记不创建或关闭它；EOF 未闭合记 TRUNCATED |
| 调用空闲/活动 | 明确开始 → 当前调用 → 匹配结束 | 开始时以显式身份核对下述冻结顺序；孤立结果/结束报错；嵌套开始不替换当前调用；重复调用另留尝试并永久阻断 |
| 单行结果组 | 一条完整结果对应一个可唯一识别的调用 | 无名、未知名、计划重复无法区分、重复结果均阻断，不按顺序猜测 |
| 汇总空闲/现代活动 | Summary → 五个唯一字段 → 完成 | 无头字段、重复字段/块、缺字段、混用旧式均报错；错误不能被后来的合法块清除 |
| 指标上下文 | 已知标签/trace/表头 → 完整数值行 | 孤立、跨错误上下文、非法值/单位报错；不发布为有效指标 |

恢复只为继续诊断，不修复已记录错误；不重绑错误记录。组正常闭合时仍有未闭合调用/汇总，一并记不完整后清空该组上下文；后续组可单独分析，整份报告仍 BLOCKED。状态码由枚举决定，不从错误文案中查找子串。JSON 与 Markdown 均展示位置、错误码、原值、单位和表格维度；格式转义不能改变身份。

## LTP 汇总与判定

A0 按冻结源码和真实日志列出支持的原生前缀、退出位及汇总格式，禁止猜测全部 LTP 输出都相同。现代汇总为 passed/failed/broken/skipped/warnings 五个唯一非负整数字段；一次调用最多一个块。旧式以 `Total Tests` 开始，后接唯一 Passed/Failed/Not Supported，核对总数及原生事件映射；映射不足的格式不支持，不能把未表达的 TBROK/TWARN 默认为 0。

字段只能在相应活动汇总中消费，不能因位于 invocation 区间就视为已校验。已出现的块必须完整且与原生结果一致；无论判据是否允许没有汇总，孤立/冲突字段都阻断。是否必须有汇总由 CRITERIA 按调用列明，不保留一个可以宽松兜底的全局 J1 开关。TINFO/TDEBUG 不计成功；TPASS/TFAIL/TBROK/TCONF/TWARN 保留记录数及冻结语义下的计数，事件与汇总分别列示，不相加。

规范结果 PASS 必须有完整且唯一的调用、所需合法正向证据和合法值，并满足[阶段契约](test001-redesign.md)的退出码、前置/清理和 LTP 条件。被测失败、跳过、警告、超时留在结果事实中；语法/归属冲突记 JUDGE_ERROR，活动组内缺项/缺结果为 MISSING；整组未开始，或有明确前置/清理失败证据而未执行的后续调用为 NOT_RUN，不能仅凭没有开始记录就声称确定未运行。并存事实全部保留，不让 judgment 单字段抹掉失败原因。所有解析错误、未知项、范围外调用、歧义及未归属结构都阻断验收；无观测不等于无错误。

每个已观察调用的完整身份 `(group, libc, invocation_id)` 必须属于本次已冻结的 selection，仅在 PROFILE 中存在不足以合法归属。已知但不在 selection 的调用记 OUT_OF_SELECTION，保留其身份、尝试、原始位置与结果，协议为 ERROR、验收 BLOCKED；无论该调用成功、失败或未结束均如此。未知于 PROFILE 的调用另记 UNKNOWN_INVOCATION。范围检查在绑定调用时执行，最终验收再核对所有观察身份均属于 selection；错误恢复不能把范围外记录重新绑定到范围内调用。它们不扩大 selected_total，不计入范围内 observed_pass/accepted_pass，也不能填补范围内缺项；只为 selection 内未完成的项生成 MISSING/NOT_RUN。该规则适用于单组、单分片及合法多分片选择，后者以已冻结分片并集为 selection，不以整个 PROFILE 代替。

## 冻结顺序与观察顺序

selection 只表达覆盖成员，不能证明执行顺序。每个 `(group, libc)` 的 `expected_sequence` 从 PROFILE 的固定有序调用列表投影到 selection；单分片保留片内顺序，整组/合法多分片选择按 PROFILE 预先冻结的分片顺序连接，不能采用 CLI 参数顺序、ID 排序或集合迭代顺序。PROFILE 必须固定片间顺序且各片无重叠，按片序连接的完整列表须等于该组/libc 冻结的调用列表；无法唯一推导序列的配置在消费前作为输入错误退出 2。序列中的完整身份恰好覆盖 selection 一次，计划中的同名调用用不同 invocation_id 表示。不同组/libc 各自核对，组调度顺序仍按构建包和采集协议校验，不凭串口行混排推断新的全局调用顺序。

`observed_sequence` 由同一解析状态机按原日志位置记录调用开始；无独立开始标记的组，仅在已审语法能唯一识别调用时，以其单行记录作为开始。不以结束、TPASS 或 Summary 的顺序代替开始顺序，也不按预期序号猜测身份。重复、嵌套、未知、范围外的开始仍保留在序列及诊断中，不过滤后再比较；损坏/身份不明的开始保留事件引用并阻断，不能补造身份。内部多条断言不是新的调用开始。

每个开始逐项与当前序号的预期身份比较，遇到不符即记 ORDER_MISMATCH、protocol=ERROR、acceptance=BLOCKED。保留预期身份、实际身份和原始位置；后续只继续诊断，不重新排序、去重或寻找后续成功来对齐。已知调用的真实身份和结果仍保留，不把 b 的成功算给预期的 a。终结时核对两序列长度和每项身份完全相等；完整前缀后提前结束记 ORDER_INCOMPLETE、protocol=INCOMPLETE（已有 ERROR 时保留 ERROR）、acceptance=BLOCKED，保留缺项/截断等独立原因，不能按已观察前缀缩小预期序列或分母。顺序吻合也不证明结束、退出码或结果合格，其他验收条件仍全部检查。

报告同时保存两序列、相等性结论及差异位置，最终验收要求序列完全匹配；仅输出 `order_matches=false` 而不阻断不合规。重判保持原 PROFILE 与 selection 推导的预期序列不变；缺乏可识别调用开始的旧证据记 ORDER_UNVERIFIABLE、protocol=ERROR 并阻断，不能根据成功结果补造执行顺序。修改执行顺序必须先更新采集 PROFILE，CRITERIA 不能单独放宽它。

| 尝试与范围 | 单次完整成功；缺 START/END、失败后成功、重复 Pass!、同名计划调用歧义、缺项/多 shard 漏项；分母不变 |

| 冻结顺序 | 预期 [a,b]，观察 [a,b] 且每次完整为正例；相邻对调 [b,a] 即使全 PASS 仍 ORDER_MISMATCH、BLOCKED；[a] 为 ORDER_INCOMPLETE；[a,a,b] 保留重复与顺序错误；[b] 保留乱序与缺项；身份不明的旧日志 ORDER_UNVERIFIABLE；多分片按冻结片序比较，颠倒 CLI 选择顺序不改变预期，内部多 TPASS 不增加调用数 |
| 指标 | 完整标签/值/单位/维度；NaN/Inf、未知标签、非法尾部、孤立 time、表格中断；无效数据不进有效指标 |
| 快照与发布 | 移动源文件仍用副本；改源码/环境变量/pycache 不能换实现，已有/链接输出不覆盖；读取超限及时终止，fsync/写失败无可消费报告 |
| 最终输出 | JSON/Markdown 和原日志偏移对应；外部日志普通分析 0、require-pass 1，非法输入 2，工具/发布失败 1；C 补真实 PASS→0 |

期望值由人工审阅的小型固定样本给出，不调用生产词法或验收函数生成预期。历史 judge 一致只是对照，已知错误允许纠正并说明差异。性质测试要求：添加失败、重复、孤立字段不能把 BLOCKED 提升为 PASS；改变信息消息不产生新结果；LF/CRLF 仅改变字节位置、不改变语义；诊断文案变化不影响状态。

变异检查至少删除“孤立字段报错”、把非法结构降为 information、按整段批量消费、让对照 PASS 授权、丢弃首次失败、从原路径重新执行、忽略调用顺序七项，每项必须被上述独立断言击中。也必须保留合法正例，防止一律拒绝伪装成正确实现。A2/A3 反例运行到 CLI/最终报告；C 再验证完整运行包，不以单测数量或 CI 全绿代替这些证据。
